# Rohit Khatwani — Videographer & Editor Portfolio

A cinematic Japanese\-contemporary inspired portfolio website for Rohit Khatwani\.

## Run locally

No build tools are required\.

1. Download or clone this repository\.
2. Open `index.html` in a browser\.

## Deploy with GitHub Pages

1. Create a GitHub repository\.
2. Upload `index.html`, `README.md`, and `LICENSE`\.
3. Go to **Settings → Pages**\.
4. Select the `main` branch and `/ (root)`\.
5. Save\. GitHub will publish the site\.

## Tech

- HTML5
- CSS3
- Vanilla JavaScript
- Inline SVG artwork
- Google Fonts

No framework or build step is required\.

## Customization

Most portfolio content is directly inside `index.html`, including:

- About section
- Services
- Skills
- Selected reels
- Clients
- Education
- Contact details

Replace the Instagram reel URLs, client links, text, and contact details with your own information when reusing the template\.
